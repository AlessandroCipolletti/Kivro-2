# Private media examples — Master Spec §§360–361

`pnpm test:browser:m10` passed 4/4 on the current tree. The new
`tests/browser-m10/media-examples.spec.ts` creates a published, seller-approved
example with actual image, MP4, WAV, PDF and Blender bytes in private SeaweedFS.
An unsigned direct object request is rejected. The marketplace reads the
approved version and renders input labels with safe image/video previews and
Blender metadata; output media uses image/video/audio/PDF viewers and generic
Blender metadata. Downloads return the original private bytes through the
authorized example route, with bounded content type, `nosniff`, a sandboxing
CSP and a generated field-based filename. Public text contains neither
storage IDs nor seller host paths. The PDF frame has a sandbox attribute.

The test also checks desktop/mobile layout, horizontal overflow and WCAG
A/AA automated accessibility. Rendered captures were inspected:
`docs/evidence/m16-browser/media-examples-desktop.png` and
`docs/evidence/m16-browser/media-examples-mobile.png`. These fixtures prove
presentation and storage authorization for approved examples. They are not
evidence that the example files were generated by a paid OpenClaw job; that is
a separate §359 requirement.
