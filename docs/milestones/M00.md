- The import gate proves only dependency direction for current source files; it does not prove semantic parity between provider profiles. Both composition roots are still structural shells.
- The manifest and job-offer schemas validate shape/version. A `paymentSecured` field in a received offer cannot establish financial truth. There is no execution or settlement path yet.
- OpenClaw detection does not verify version compatibility, seller consent, effective sandbox policy, or output safety. All remain blocking execution prerequisites. Live skill/config inspection was disabled after `skills list --json` attempted to modify personal state on OpenClaw 2026.8.2.
- The safe local smoke probe now verifies version detection only; fixture parsers do not certify live read-only discovery or production Worker readiness.
