## Concise implementation plan

1. Finish the single normalized versioned I/O contract: safe scalar defaults, file presets/limits, semantic tags, simple conditions, output schema and contract compatibility. Drive browser/API/Worker validation from this contract, never from independent field lists.
2. Model private asset ownership, source/target job grants, immutable metadata, retention, authorization and object keys in shared Core. Add forward-only PostgreSQL schema and provider-neutral storage port. Bytes go only to private object storage; local Worker files are temporary.
3. Implement streaming upload/download and object integrity through an S3-compatible adapter; use a private S3-compatible local service in Compose and keep Netsons/AWS business semantics shared. Direct transfer and short-lived authorized result access must avoid routing large bytes through the API server.
4. Build private per-attempt input staging and bounded output collection. Reject path traversal, symlinks, special/hard-linked files, oversized files, MIME/extension/signature mismatch and archives by default. Validate `/job/output/result.json` against the versioned output contract, then replace local paths with authorized asset IDs.
5. Wire the cloud finalization service only after M07 authoritative job/attempt state exists. Successful delivery requires durable object checks and cloud commit before payment settlement; browser disconnect and Worker disappearance cannot erase results.
6. Test pure contract logic, file adversaries and real Docker staging; then PostgreSQL/MinIO authorization and failure injection. Run buyer/Worker/API/Agent/browser and both-provider conformance gates immediately when M07/M10/M11/M13/M19 supply those consumers.

Keep paid execution disabled while this is incomplete.
