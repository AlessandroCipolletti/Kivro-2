# Seller Worker

The host-native Worker foundation has local SQLite pause/audit state, a version-only isolated OpenClaw probe, a read-only metadata discovery adapter, an Ed25519 device identity with OS keychain primary storage and explicit encrypted-file fallback, and a CLI (`pnpm worker health --json`, `pnpm worker doctor --json`, `pnpm worker pause --all`). M03 seller import drafts and explicit selection/consent records are stored in a separate private local SQLite file; discovery candidates carry no consent or execution permission. The CLI reports `NOT_READY` until identity pairing, cloud connection, payment, manifest, runtime and sandbox gates are implemented and verified. `resume` currently fails closed because those checks do not pass.
